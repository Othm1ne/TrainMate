# TrainMate

Meet your sport mate through our app.

TrainMate is a Flutter app for finding training partners nearby: swipe through
people who share your sports, match, chat, and join local sport events.

## Features

- **Auth** – email/password (with password reset), Google, Apple (iOS/macOS/web)
- **Profile** – photo, level, age, sports, bio, auto-detected location, badges,
  completion score; view other users' profiles
- **Find a partner** – swipe deck of people who share your sports, sorted by
  distance, with filters (sport, level, distance); mutual likes create a match
- **Chat** – real-time messages with your matches; mute, block/unblock, report
- **Events** – create events (cover photo, category, place, date), join/leave,
  see attendees and distance, "Going" filter, delete your own events
- **Premium** – unlimited likes (free: 20/day) and "See who liked you"

## Stack

Flutter · Firebase Auth · Cloud Firestore · Firebase Storage · geolocator/geocoding

```
lib/
  main.dart                 Firebase init
  firebase_options.dart     generated by `flutterfire configure`
  src/
    app.dart                MaterialApp + AuthGate (onboarding / complete profile / app)
    data/models/            UserProfile, EventItem, ChatThread, Message
    data/services/          auth, users, matches, chats, events, storage, location
    features/               one folder per screen group (auth, home, chat, events, profile, premium)
    shell/main_shell.dart   bottom navigation
    shared/                 sports list, shared widgets
```

## Setup

1. Install Flutter (3.32+) and the Firebase CLI (`npm i -g firebase-tools`).
2. Create a Firebase project and enable:
   - **Authentication** → Email/Password, Google (and Apple if you ship on iOS)
   - **Cloud Firestore**
   - **Storage**
3. Connect the app (this overwrites `lib/firebase_options.dart`):
   ```bash
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
4. Deploy the security rules and indexes:
   ```bash
   firebase use <your-project-id>
   firebase deploy --only firestore:rules,firestore:indexes,storage
   ```
5. Run:
   ```bash
   flutter pub get
   flutter run
   ```

### Google Sign-In

- **Android**: add your SHA-1 (`cd android && ./gradlew signingReport`) in the
  Firebase console → Project settings → Android app, then re-run `flutterfire configure`.
- **iOS**: add the `REVERSED_CLIENT_ID` from `GoogleService-Info.plist` as a URL
  scheme in `ios/Runner/Info.plist`.

## Data model (Firestore)

| Path | Content |
|---|---|
| `users/{uid}` | profile, `lat`/`lng`, `blocked[]`, `isPremium`, daily like counter |
| `users/{uid}/swipes/{otherUid}` | `{from, to, liked, at}` |
| `chats/{uidA_uidB}` | `members`, `memberInfo`, `lastMessage`, `mutedBy`, `blockedBy` |
| `chats/{id}/messages/{id}` | `{senderId, text, sentAt}` |
| `events/{id}` | event details, `creatorId`, `attendeeIds[]`, `attendeePhotos{}` |
| `reports/{id}` | user reports for moderation |

## Known limitations

- Premium has no payment provider yet: "Upgrade now" sets `isPremium` directly.
  Before release, connect in-app purchases / Stripe and set the flag from a
  Cloud Function (then lock `isPremium` in `firestore.rules`).
- No push notifications yet (Firebase Cloud Messaging would be the next step).
